# Sofran Musik Studio — Netlify rebuild

Versi rebuild terpisah dari proyek Framer. Branch: `netlify-rebuild`.

## Deploy ke Netlify
- Import repository `hiromusik0/Sofran-Musik-Studio`
- Pilih branch `netlify-rebuild`
- Build command: kosong
- Publish directory: `.`
